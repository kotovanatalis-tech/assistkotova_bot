# Личный планер: Telegram-бот + мини-приложение

Запуск на Railway через GitHub. Займёт около 20 минут, один раз.

В репозитории 4 файла: `bot.js` (бот и приложение), `server.js` (сервер для Railway), `package.json` и эта инструкция. Устанавливать ничего не нужно.

**Про оплату.** Насколько я знаю, у Railway нет постоянного бесплатного тарифа: сначала даётся пробный кредит, потом нужен план Hobby (около $5 в месяц). Этому боту тарифа Hobby хватает с запасом. Актуальные цены проверь на railway.com/pricing.

## 1. Создай бота

1. В Telegram открой **@BotFather** и отправь `/newbot`.
2. Придумай имя и юзернейм, который заканчивается на `bot`.
3. Сохрани **токен** вида `7123456789:AAH...`. Никому его не показывай.

## 2. Загрузи файлы на GitHub

1. Зарегистрируйся на **github.com**.
2. Справа вверху нажми **+ → New repository**. Название: `planner-bot`. Выбери **Private**. Нажми **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file**.
4. Перетащи туда 4 файла: `bot.js`, `server.js`, `package.json`, `README.md`.
5. Нажми **Commit changes**.

## 3. Создай проект на Railway

1. Зайди на **railway.com** и нажми **Login → GitHub**.
2. **New Project → Deploy from GitHub repo**. Если репозитория нет в списке, нажми **Configure GitHub App** и дай доступ к `planner-bot`.
3. Выбери `planner-bot`. Первый запуск упадёт с ошибкой про BOT_TOKEN. Это нормально, токен добавим на следующем шаге.

## 4. Добавь токен и свой ID

1. Узнай свой Telegram ID: напиши боту **@userinfobot** любое сообщение, он пришлёт число после «Id», например `123456789`.
2. Нажми на сервис → вкладка **Variables → New Variable** и добавь две переменные:

| Name | Value |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `OWNER_ID` | твой ID (только цифры) |

С `OWNER_ID` бот отвечает **только тебе**. Остальным он пишет «Это личный бот», и чужие люди не смогут открыть приложение, даже если найдут бота.

## 5. Подключи диск для данных (обязательно!)

Без этого шага все дела, траты и уроки будут стираться при каждом обновлении.

1. На схеме проекта нажми правой кнопкой по сервису → **Attach Volume**. Если такого пункта нет: кнопка **+ Create → Volume**, затем выбери свой сервис.
2. **Mount path:** `/data`

## 6. Получи адрес для приложения

1. Сервис → **Settings → Networking → Generate Domain**. Если спросит порт, оставь предложенный.
2. Там же в **Settings** проверь, что **Serverless (App Sleeping)** выключен. Иначе сервер будет засыпать, и напоминания не придут.
3. Вкладка **Deployments** → у последнего деплоя нажми **⋮ → Redeploy**.

## 7. Проверь и запусти

1. Открой **Deployments → View logs**. Там должны быть строки:
   - `✅ Сервер запущен на порту …, данные в /data`
   - `Настройка Telegram: ✅ Готово!`
2. Напиши своему боту `/start`.

Что делать, если что-то пошло не так:
- **«Папка /data не найдена»** — не подключён Volume (шаг 5).
- **«Нет публичного адреса»** — не создан домен (шаг 6).
- **«Что-то пошло не так»** — проверь токен.

## Как пользоваться

Всё можно просто писать боту:

| Что пишешь | Что происходит |
|---|---|
| `купить памперсы` | дело; бот спросит колонку: сон ребёнка, ВБ, важно и срочно, важно и не срочно (или банк идей) |
| несколько строк | каждая строка станет отдельным делом |
| `завтра позвонить в садик` | дело на завтра |
| `15.10 14:00 врач`, `завтра в 10 стоматолог`, `пт 18:00 созвон` | событие в календаре, напоминание за день и за час |
| `20.10 день рождения мамы` | событие на весь день, напоминание накануне |
| `350` или `350 кофе` | трата; бот спросит: работа, быт, на себя, другое |
| `+15000` или `+15000 уроки` | доход; бот спросит: работа или другое |
| `💡 рилс про утро` или `идея: …` | сразу в банк идей |
| HTML-файл | урок сохранится, лексика будет подсвечена |

Дела, отправленные после 18:00, по умолчанию ставятся на завтра. Это можно переключить кнопкой под сообщением.

**Кнопки под полем ввода:** «😴 Малыш уснул» показывает дела из колонки «Сон ребёнка» и даёт отмечать их прямо в чате. Также есть «📋 Дела на сегодня», «➕ Доход» и «📅 Ближайшее».

**Бот сам пишет:**
- за день и за час до каждого урока и события;
- в 21:00: что завтра, работает ли муж, предложение перенести несделанное и вопрос про дела на завтра;
- по воскресеньям в 20:00: итоги недели (дела, деньги, соцсети, слова) и напоминание внести доход и выставить цели.

**Приложение** открывается кнопкой «Планер» слева от поля ввода. В нём пять разделов:
- **Дела.** Матрица из 4 колонок. Через «⋯» дело можно перенести в другую колонку или на другой день.
- **Календарь.** Уроки, события и смены мужа. Внизу можно изменить постоянное расписание и график 2/2.
- **Деньги.** Цели на неделю и месяц, прогресс и все записи.
- **Соцсети.** Цели и выполнение по неделям, плюс банк идей.
- **Язык.** Уроки, слова и повторение карточками. В уроке нажми на жёлтую подсветку или выдели любое слово, чтобы добавить его в «Повторить позже». Слова возвращаются через 1, 3, 7, 14, 30 и 60 дней.

Уже настроено: уроки по вторникам в 11:00 и по пятницам в 11:00 и 13:00 (по Москве), смены мужа 2/2 с 3 октября по 9 ноября.

## Как обновлять код

1. На GitHub в репозитории нажми **Add file → Upload files**.
2. Перетащи новый `bot.js` (или другой файл) с тем же именем и нажми **Commit changes**.
3. Railway сам заметит изменения и перезапустит бота за 1–2 минуты.

**Данные при этом сохраняются**: база и уроки лежат на диске `/data`, а не в коде. Только не удаляй Volume.
